A single slogan for a Solana wallet agent, written to `/output/entry.txt`:

> Send SOL like sending a text — your wallet agent handles the rest.

66 characters, 13 words, one line — inside the gate (1–140 chars, at most 20 words).

## Why this line

Picked by hand from six candidates against the judge brief, in order: it names
SOL and the wallet agent outright; the texting comparison is a fresh, everyday
image instead of a stock crypto line about keys, moons or bags; the promise is
clear to a newcomer on one read; the parallel contrast ("send like a text" /
"agent handles the rest") sticks in the ear; and it promises nothing a wallet
agent cannot deliver.

## Run

```sh
python3 main.py
```

Writes the slogan to `/output/entry.txt` (or `output/entry.txt` locally),
after asserting the gate: 1–140 characters, a single line, at most 20 words.
